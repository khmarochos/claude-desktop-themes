# desktop-themes

Мод для Claude Desktop, що додає теми оформлення й перемикає їх командою `/theme-custom`.

## Теми

| Назва | Опис |
| --- | --- |
| `paper` | Тепла паперова сторінка вдень, папір при лампі вночі (за замовчуванням) |
| `midnight` | Холодний синій |
| `forest` | Мох і хвоя |
| `field` | Небо й соняшники |
| `lilac` | Блідо-бузковий, майже білий, із зеленими акцентами й ледь помітним анімованим фоном: повільне зелене й бузкове сяйво та зелені цяточки, що спливають угору; вночі — бузкові сутінки |
| `terminal` | Класичний зелений термінал: люмінофор на чорному, анімований CRT-фон зі скан-лініями й мерехтінням, а замість стандартного індикатора роботи — зелений курсор █, який блимає 5 разів і підскакує (лише темна) |

Усі теми, крім `terminal`, мають світлий і темний варіант. Якщо в системі ввімкнено «Зменшити рух», анімації зупиняються.

## Команди

```
/theme-custom            — список тем
/theme-custom terminal   — увімкнути тему
/theme-custom off        — повернути стандартну тему Claude
```

Вибрана тема запам'ятовується між сесіями. Теми малюються в застосунках Claude Desktop і Claude на мобільному; термінал і редактори їх не показують.

## Встановлення

У сесії Claude Code в терміналі:

```
/plugin install desktop-themes --marketplace khmarochos/claude-desktop-themes
```

Відповідайте `y`, щоб додати каталог, і оберіть область `user`, щоб мод працював у всіх сесіях.

З командного рядка:

```bash
claude plugin install desktop-themes --marketplace khmarochos/claude-desktop-themes
```

У Claude Desktop, де `/plugin` не працює: натисніть **+** біля поля вводу → **Plugins** → **Add marketplace** з `khmarochos/claude-desktop-themes` → **Add plugin**.
